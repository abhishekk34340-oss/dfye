Who We Are

Welcome to ChatWave, a simple real-time chat application designed to make online communication fast and easy.

Our application allows multiple users to join a chat, send messages instantly, and see other users who are currently online.

Our Features

  • Real-time messaging
  • Usernames
  • Message timestamps
  • Online user count
  • Join notifications
  • Leave notifications

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express.js
  • Socket.IO

Our Goal

The goal of this project is to demonstrate how real-time communication works on the web using Socket.IO and Node.js.
